# Hangang Runtime

한강 월드의 공용 서버 기반입니다. 호패의 인증, 품계의 권한, 수문장의 네트워크 판정은 각 모듈이 소유합니다.

첫 구현은 gRPC 필수 mTLS, TLS 파일 제한, 동시 연결 2,048개, 연결당 요청·스트림 64개, 헤더 8KiB, 요청 시간 1초, TCP_NODELAY를 공유합니다. 자격 역할, 전체 판정 처리량, 메시지 크기와 스냅샷 판정은 각 서버가 관리합니다.

네이티브 프로토콜, 감독 실행, 리스너 인계와 관측 기능의 공용화는 후속 작업입니다. 각 서버는 계속 독립적으로 배포합니다.

공용 TLS 파서는 네이티브/관리 mTLS 설정에도 사용합니다. serve_https는 관리 HTTP/1.1 연결 2,048개, TLS 핸드셰이크 3초, 헤더 64개·버퍼 32KiB, 헤더 읽기 5초, 연결 수명 300초, 종료 드레인 5초를 제한합니다. 역할·본문 제한은 도메인이 소유하며 네이티브 판정 프로토콜을 대신하지 않습니다.

serve_connections는 TCP 연결 제한과 연결 태스크 소유권을 공유합니다. 실제 접속
주소·TCP_NODELAY를 유지하고 초과 연결을 거부합니다. 지정된 시간 동안 드레인한
뒤 남은 태스크를 취소하고 회수하며 서버 취소도 소유한 태스크를 취소합니다. TLS,
네이티브 프레이밍, 자격, 연결 수명과 판정은 핸들러가 소유합니다. 관리 HTTPS에
적용했으며 네이티브 리스너 적용은 소비자별 검증이 필요합니다. 실제 소켓으로
용량 보존·재사용, 종료와 소유 서버 취소를 검증합니다.
